## 历史恢复

以上文件的整理前版本保存在 Git 标签 `v1.1.0`。例如，在仓库根目录导出旧原型到临时文件：

```bash
git show 'v1.1.0:outputs/知枝-手机预览.html' > /tmp/zhizhi-old-preview.html
```

其他旧文件也可按标签和原路径查阅。历史标签和旧版本交付包不修改；1.1.0 的源码压缩包继续对应原发布提交。

## 语言统计规则

根目录 `.gitattributes` 用 `linguist-detectable=false` 排除历史实验与归档代码，用 `linguist-generated=true` 标记可重建产物。正式源码保持自动语言识别，不将其他语言伪装为 TypeScript，也不排除仍在使用的原生插件或工程工具。

这是 [GitHub Linguist 支持的统计规则](https://github.com/github-linguist/linguist/blob/main/docs/overrides.md)。GitHub 语言条由服务端重新计算，未刷新前可能仍显示旧值；正式应用源码字节占比与整个仓库的 GitHub 语言占比不是同一个口径。
