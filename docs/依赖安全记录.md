# 知枝：依赖安全记录

记录 `npm audit` 报告的问题、评估结论和复查条件。看到同样的提醒时先查这里；有新提醒时开 Issue 评估，结论补进本文。

**不要运行 `npm audit fix --force`**：它会为了消除提醒而跨主版本改动依赖（包括降级），可能破坏构建和安卓打包。

## 2026-10-28：uuid / xcode / @capacitor/cli（3 个中等风险）

`npm audit` 报告 3 个中等风险，来源是同一个漏洞：

```
@capacitor/cli 8.5.3 → xcode 3.0.1 → uuid 7.0.3
```

| 项目 | 内容 |
| --- | --- |
| 漏洞 | [GHSA-w5hq-g745-h8pq](https://github.com/advisories/GHSA-w5hq-g745-h8pq)：uuid 11.1.1 之前，`v3` / `v5` / `v6` 在传入 `buf` 参数时缺少缓冲区边界检查 |
| 触发条件 | 调用 `uuid.v3/v5/v6` 并传入 `buf` |
| 实际调用 | `xcode` 只调用 `uuid.v4()`（`node_modules/xcode/lib/pbxProject.js`），不调用 v3/v5/v6，也不传 `buf` |
| 使用范围 | `xcode` 只被 `@capacitor/cli` 的 iOS 工程处理代码（`dist/util/xcode.js`）引用；本项目没有 iOS 平台 |
| 是否进入应用 | 否。`@capacitor/cli` 是开发命令行工具，`src/` 未引用它，构建产物中没有相关代码 |
| npm 建议 | `npm audit fix --force` 把 `@capacitor/cli` 降到 8.4.3。会与 `@capacitor/core`、`@capacitor/android` 8.5.3 版本不一致，并丢失 8.5.x 的修复 |

**结论：暂不处理。** 漏洞代码路径在本项目中不可达，也不进入应用包；可用的修法（降级 CLI、强制覆盖 uuid 版本跨越 7 → 11 主版本）带来的风险大于收益。

**复查条件**（满足任一项时重新评估）：

- 升级 `@capacitor/cli`：上游 `xcode` 4.0.0 已不再依赖 uuid，Capacitor 升级 xcode 后提醒会自然消失
- 项目加入 iOS 平台
- `npm audit` 出现新的提醒，或该漏洞的影响范围被修订
