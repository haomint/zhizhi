# 知枝 · 本地版 0.2（DeepSeek）

## 开始使用

1. 双击同目录的 **启动知枝.cmd**。程序会寻找可用的 Python 3.10+，启动本机服务并打开浏览器。
2. 点击页面右上角的 **DeepSeek · 待设置**。
3. 粘贴在 DeepSeek 开放平台创建的 API Key，点击 **保存并测试连接**。
4. 出现绿色“连接成功”后，关闭设置窗，选择“开始一段学习”。

默认地址为 `https://api.deepseek.com`，默认模型为 `deepseek-flash`，通常不必展开高级设置。API Key 需要由用户自行提供。

**高数演示树是固定样例。** 接入 DeepSeek 后，新建正式学习树才会针对你的需求生成内容，示例树本身仍保持演示性质。

## 本轮修复

- 批处理使用 ASCII 内容和 Windows CRLF 行尾，调用英文命名的脚本，避开中文脚本名与控制台编码问题。
- 自动寻找可运行的 Python，从其他文件夹启动也能定位完整应用。
- 仅监听本机地址。默认端口不可用时自动选空闲端口，并核对项目、版本和进程，避免连回其他旧服务。
- 重复启动复用同一服务，错误保留在 `data/server.log`。
- DeepSeek 地址和模型预填，使用当前填写内容“保存并测试”；完整接口地址会自动规范化，避免重复拼接。
- 连接测试只需短文本响应；知识生成开启 JSON 输出，关闭额外思考模式，优先减少等待。
- 具体区分密钥错误、余额不足、接口不存在、限流和服务繁忙。提示留在设置窗口中。
- 设置可持久保存，API Key 可选择用 Windows DPAPI 加密，仅当前 Windows 账号可解密。不会明文写入学习数据库、页面返回或学习档案导出。
- 配置状态区分待设置、待测试、已连接、连接未通过。
- 输入需求后可直接点击“整理需求”，不必先保存每段文字。

## 本地运行的含义

应用、个人资料、学习树与图片保存在本机，未部署网站或云端数据库。使用 DeepSeek 生成内容仍需联网，相关学习上下文会发送给所选模型服务。没有 API 时可以浏览固定示例。

卡片继续采用少量内容、多页呈现，仅文字和静态图片，不生成动画演示。

## 保存和停止

- 学习记录：`data/grove.sqlite3`。
- 独立的加密模型配置：`data/model-settings.json`。
- 启动日志：`data/server.log`；不主动记录密钥、模型请求正文或学习内容。
- 页面支持导出 JSON 学习档案，目前没有导入功能。
- 关闭浏览器后服务继续保留。双击 **停止知枝.cmd** 退出，重新启动后进度仍在。
- 换 Windows 账号后需要重新填写 API Key。

可选环境变量：`DEEPSEEK_API_KEY`，或 `MODEL_BASE_URL`、`MODEL_NAME`、`MODEL_API_KEY`。环境变量配置优先于保存的配置。

## 遇到错误

| 提示 | 检查事项 |
| --- | --- |
| HTTP 401 | API Key 是否有效、完整、来自所选服务 |
| HTTP 402 | DeepSeek 开放平台的 API 账户余额 |
| HTTP 404 | 高级设置中的地址和模型名称 |
| HTTP 429 / 503 | 稍后重试，避免连续提交 |
| 启动失败 | `data/server.log`，以及应用文件是否齐全 |

## 验证与接口依据

本轮使用本地模型模拟服务验证接口格式及失败处理，并在正常 Windows 用户环境中实际执行启动、停止和重启，覆盖中文路径、不同工作目录、端口占用、重复启动，以及加密密钥的恢复。

没有用户的有效 API Key 时，不能宣称真实 DeepSeek 账户已经连接成功。真实结果以“保存并测试连接”的返回为准。
