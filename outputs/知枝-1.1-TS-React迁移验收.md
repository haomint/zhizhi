# 知枝 1.1：正式 TypeScript / React 迁移验收

日期：2026-10-24。版本：1.1.0，versionCode 6。此次修改的是正式应用 `outputs/learning-grove/`，独立实验仅作为前期证据保留。

## 已完成的代码迁移

| 原实现 | 当前实现 |
| --- | --- |
| `static/app.js`、`v1-ui.js` 的 DOM 模板与全局事件 | `src/ui/*.tsx` 的 React 页面、组件、表单、导航与弹窗 |
| `src/*.mjs` 的学习/Pi 核心 | `src/core/*.ts`，保留原业务行为并补充类型 |
| `static/mobile-service.js` 覆盖全局 fetch | `src/application/service.ts` 的类型化应用服务、任务队列和状态订阅 |
| UI 与存储、原生能力交织 | `src/platform/` 中的 Repository / Platform 接口与适配器 |
| 无统一类型契约 | `src/contracts.ts` 定义 Action、Snapshot、档案和模型阶段结果 |
| 历史 Python 桌面实现混在正式入口 | `legacy/desktop/` 明确归档，退出正式运行路径 |
| 手写静态脚本打包 | Vite 构建 React + TS，严格类型检查、Prettier 与检查命令 |

正式应用有 16 个 TS/TSX 源文件，没有 `any`、`@ts-nocheck`、`@ts-ignore`、全局 fetch 覆盖或 window.ZhizhiPi 依赖。Android Java 插件和必要工程脚本保留各自职责；TS 编译后在 WebView 中执行 JavaScript。
