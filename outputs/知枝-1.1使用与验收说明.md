# 知枝 1.1：使用与验收说明

版本：1.1.0，versionCode 6。正式应用已经从原生 JS 界面迁移为 React + TypeScript；学习功能范围维持原 MVP，档案格式保持兼容。

## 安装与旧记录

使用 `知枝-1.1.0.apk`。它沿用 1.0.1 的应用 ID `app.zhizhi.personal.v1` 和 v1 签名。构建脚本与核对记录确认包身份和签名；目标手机覆盖安装、数据保留和生命周期仍须实测。建议先在 1.0.1 导出 JSON 留存，不要求卸载原应用。

更早的 0.6.1、0.7 和原始 1.0 应用身份/签名不同，继续保留旧 App，通过导出/导入 JSON 迁移。密钥不在档案中；同一 v1 应用更新沿用原生加密存储，换设备需要重新填写。

## 主要流程

1. 在“个人 → 模型设置”保存并测试 DeepSeek Key。浏览器预览不接收真实 Key，只运行本地功能与固定演示。
2. 开始学习，描述主题、用途和希望达到的程度；必要时补充一个关键问题，确认学习约定与路线。
3. 提供相关教材片段，或检索有限的百科摘要。支持粘贴、TXT/Markdown；不直接解析 PDF/Word。
4. 按节点阅读短卡片。可针对当前卡片主动提问，通过“调整讲法”提出明确偏好。
5. 通过知识树查看路线和浏览进度。加强学习由用户主动进入，检查记录绑定内容版本，后续一次答错保留此前有效证据。
6. “结束本次学习”整理新增经历；下次继续使用相关记录。个人资料可搜索、纠正和删除。
7. 在个人页面导出、合并/替换导入档案，或恢复导入前档案。
8. 生成过程中仍可阅读已保存内容，任务面板可取消或重试；退出重开后未完成任务标记为中断。

## 验证边界

28 项自动回归通过，包括真实 Pi 循环与模拟模型传输、新服务的事务、取消、旧结果拦截、档案恢复和旧文档迁移。正式 React 界面 13 项浏览器检查通过，覆盖资料、反馈、答疑、自愿加强、结算、知识树、档案、离线阅读和手机/桌面布局。

APK 构建/签名/资源检查结果见正式源码中的 `apk-verification.json`，汇总见 `知枝-1.1-TS-React迁移验收.md`。尚未使用真实 DeepSeek Key，尚未实测目标安卓手机或覆盖安装，不宣称内容准确性、手机长期稳定性与学习效果已经验证。

手机验收至少完成一次“需求 → 资料 → 一个完整小节 → 问答/反馈 → 结算 → 自愿加强 → 重开继续”，再检查断网、取消、前后台切换、档案恢复和从 1.0.1 更新后记录保留。
