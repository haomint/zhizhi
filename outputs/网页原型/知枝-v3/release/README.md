# 知枝网页总版本 1.0.1

当前用户确认的完整总版本。保留居中“要学什么”单输入框、选择题补问、无成果测验的连续阅读，以及“上一张”和跨已读小节回看。

在本目录运行 `python3 -m http.server 4184`，打开 `http://localhost:4184/index.html`。个人中心填写API Key、模型名、HTTPS接口地址，然后点“测试连接”；例如DeepSeek地址 `https://api.deepseek.com`，模型 `deepseek-chat`；兼容接口的 `/v1` 前缀按服务商要求填写，完整 `/chat/completions` 地址也支持。浏览器能否直连还取决于服务商的CORS配置，安卓通过原生HTTPS网络桥接。真实API Key由用户自己填写，本包没有真实凭据。

安卓安装版为1.1.1（网页与安卓沿各自版本线编号），详情见 `android/README.md`。当前签名为独立阅读版签名，可与旧App共存。

本轮浏览器验证使用模拟模型与桥接；APK签名与页面资源一致性已核对，没有真机安装或真实账号调用记录。
