# 知枝 1.0：使用与验收说明

版本：1.0.1（versionCode 5）｜续作核对日期：2026-10-24

## 这次交付是什么

这次是可安装的个人学习 MVP 1.0，已把此前预设的核心流程接入应用，不再只有规则文件：需求整理、学习路线、真实材料读取、知识整理、页序、卡片、内容检查、主动问答、反馈适配、活动结算、个人记录、自愿加强、知识树、档案导入导出和生成任务恢复。

模型运行采用手机内 Pi Core；学习档案存本机，Key 由 Android Keystore 加密。生成内容仍需要 DeepSeek 网络和用户自己的 Key。AI 内容检查是辅助机制，不是对所有事实正确性的保证。

## 安装与旧版迁移

- 本次安装包为 `知枝-1.0.1.apk`，应用 ID `app.zhizhi.personal.v1`，与先前 0.6.1、0.7 整合版及原始 1.0 并行安装，不直接覆盖它们。旧版和其中资料保留，无需卸载。
- 先前签名文件属于上一会话系统用户，当前会话无法读取。本次使用另行保留的 v1 签名，没有修改旧密钥。以后更新本 v1 应用应复用 `work/release-signing/` 中该签名；当前 APK 的证书摘要见源码 `apk-verification.json`。
- 迁移时，在旧 App 导出 JSON，再到新版的“个人 → 导入学习档案”选择合并。确认记录完整后再自行决定旧 App 的保留方式，不把卸载旧版作为迁移步骤。
- API Key 不随档案迁移；新安装后需填写。合并导入会生成独立学习树副本，避免覆盖当前内容；替换导入会保留一份本机恢复点。
- 独立 Pi 技术验证 App 仍是另一应用，不是学习档案来源。

## 从第一次学习开始

1. 在“个人 → 设置”保存并测试自己的 DeepSeek Key。模型名称可修改。
2. 从首页或学习库新建学习，说明想学什么、用途及希望达到的程度。模型每轮至多补问一个问题；核心缺口必须补充，辅助信息可留待以后。
3. 确认主题、目标和偏好，建立路线。正文按一个完整节点准备，不一次生成整门课程。
4. 打开“学习资料”：可检索百科摘要，也可粘贴教材片段、导入 TXT/Markdown。填写书名、章节或页码可帮助追溯。1.0 不直接解析 PDF、Word 或付费网站。
5. 读卡片：先定义诠释，再完整例子，按需区分、应用和拓展。当前节点完整准备后才发布；可以随时主动提问。
6. 想换讲法时用“调整讲法”。明确偏好立即参与后续生成；尚未阅读的预备内容会标记为待更新。
7. “结束本次学习”整理新增经历和个人策略，不追加问卷。回学习空间时也会尝试结算待处理活动；没有新事件不会重复整理。
8. 想检验时单独点“自愿加强学习”，一次一个小问题。通过后出现橙色标记，绑定当时内容版本；关闭即可继续阅读，不影响主线。

固定演示树不调用模型；其第一节提供固定加强示例。正式学习树会按各节点生成加强问题。演示回答与模拟测试均有标注，不冒充真实模型结果。

## 内容与资料如何生成

```text
任务与相关个人经历
  → 读取用户资料 / 有限百科检索
  → 知识要点及真实材料 ID
  → 页序与覆盖检查
  → 定义、例子和必要扩展
  → 七项 AI 内容检查
  → 最多一次修订
  → 程序验证并一次保存
```

核心依据不足时停止并保留任务原因。资料被移除后，相关旧内容标注需重新核验。每个节点可查看内容版本、知识要点及来源；重新生成成功后保留最多三份历史内容，可恢复上一版。内容变化使旧加强证据失效。

联网检索采用中文 Wikipedia 的搜索与正文摘要接口，不是全网搜索。每次最多三个摘要，不能替代专业教材；用户单份材料最多 24000 字，单次任务最多选取三份、每份前 4000 字，建议直接导入相关章节片段；模型发现核心缺口时至多补查一次。资料网络失败可改用粘贴/导入，不自动编造引用。检索仅发送关键词，不发送个人记忆或模型 Key。

资料接口依据：[MediaWiki TextExtracts 官方说明](https://www.mediawiki.org/wiki/Extension:TextExtracts/en)。百科摘要保留条目链接、位置及 CC BY-SA 来源说明。

## 个性化与记忆

- 区分阅读经历与掌握证据，不从“以前学过高数”直接推定熟练。
- 只选取与任务相关的个人记录；可以联系以前学过的内容，但不会把所有历史塞进每次请求。
- 结算按事件范围去重，只有明确偏好/反馈可以形成新的讲解策略。一次答错或一个问题不产生固定能力标签。
- 删除/纠正记录会排除关联事件、相关对话上下文和衍生策略；原对话保留给用户查看。删除不会把历史卡片从屏幕上全部抹去。
- 个人策略调整不等于改写通用 skill。通用规则仍随软件版本发布，自动全局升级按原约定后置。

1.0.1 修复了合并导入后记忆与原始事件关联丢失的问题：资料副本会同时映射记忆证据、相关对话、个人策略和结算位置，避免再次结算重复处理，遗忘操作仍能排除导入后的旧证据。并发合并的事件按序号整理，不因数组顺序导致遗漏或重复结算。

同一内容版本加强通过后，后续一次答错只新增本次困难，不删除原有通过证据；打开加强入口也不会清空记录。显示本次结果的同时保留此前标记。内容版本改变时仍需重新检查。

路线变更先展示建议，用户确认后应用；旧节点和问答保留。修改学习目标也会使在途旧任务失效。

## 阅读连续性与失败恢复

- 当前小节生成成功后，可在阅读时准备下一节。可在资料面板关闭自动准备或自动百科检索。
- 模型请求期间可翻阅已保存卡片、保存阅读位置。底部状态条显示当前阶段，可停止任务。
- 每阶段最多四次模型请求、六次只读工具执行；单个任务总时限六分钟，不无限重试。
- App 被关闭后，已保存内容保留；重开将未完成任务标成中断，可在任务列表重新开始。系统后台持续执行不作保证。
- 网络失败、检查失败、任务取消、旧结果或本地保存失败均不发布半成品。
- 档案导入校验格式、数量、ID、图片及关键内容结构；合并重映射 ID，替换保留恢复点。密钥不在导出档案中。

## 建议的手机验收

安装后，选择一个有教材片段的小主题，走完“需求 → 资料 → 一个小节 → 主动问答 → 反馈 → 小结 → 自愿加强”，再退出重开。之后试一次断网、取消生成、档案导出和导入。真实模型若返回契约不符，会保留任务失败原因，便于后续定位。

这版覆盖约定的个人 MVP 核心范围。云同步、多人学习、PDF/Word 解析、多搜索提供方、自动全局 skill 升级与应用商店发布不属于本轮交付。
