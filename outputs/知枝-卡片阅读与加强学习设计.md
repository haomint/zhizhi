## 一、已选定：主线阅读与加强学习独立

### 1. 知识树状态

| 表现 | 含义 | 触发 |
| --- | --- | --- |
| 未点亮 | 尚未完成首次浏览 | 初始状态；学习中位置另外保留 |
| 绿色点亮 | 已学习，表示完成内容浏览 | 首次读到节点末页并点击继续 |
| 橙色与辅助符号 | 加强学习通过，获得该目标的掌握标记 | 用户主动进入加强学习，检查通过后保存 |

绿色/橙色为当前配色方案，颜色之外配符号或文字。进度指浏览进度，不能称为掌握率。节点已变橙色后再次阅读，不退回绿色。

### 2. 加强学习入口

- 入口放在知识树节点详情中；不在阅读结束时弹出，不要求每节选择。
- 用户可以随时主动进入；加强学习不改变主线阅读位置，不锁住后续内容。
- 取消自评掌握；不提供要求用户判断自己能力的常驻任务。
- 默认主线是讲述和完整例子，问题由用户主动提出；加强学习才提供需要作答的小问题。
- 暂不把未点亮节点强制设为不可加强，允许用户自主探索；没有完成阅读就通过时，阅读进度与通过记录仍分别保存。

### 3. 通过依据与失败处理

问题围绕节点约定目标：了解型目标检查含义、用途与限制；计算或应用型目标才检查对应操作。每个节点先定义目标及判定依据，再生成少量题目，不统一要求所有学科同样题型、同样数量。

选择题由明确答案和解释判定；开放回答依据预设要点判断，不按字面措辞硬匹配。语义不明确时说明缺少哪部分证据，不直接判成用户不会。具体题量、难度及通过规则仍需下一轮试用确定。

通过表示当前目标范围内有检查证据，不代表永久掌握整门学科。未通过时保留绿色点亮，直接给出解释，可重试、回看或退出；不扣阅读进度、不弹失败警告、不自动安排强制补课。

重试优先使用等价新例子，避免直接照抄刚展示的答案。当前尝试未通过，不删除此前有效的通过记录；用户可查看新的具体困难。

### 4. 最小保存与运行边界

分别保存阅读记录和加强记录。加强记录至少包含节点 ID、节点目标版本、问题/答案版本、用户作答、判定依据、结果与时间。节点目标实质改变时，旧记录保留并注明对应旧目标，不直接冒充新版通过证据。

保存成功才改变节点标记；断网或写入失败保留原状态。退出加强学习后恢复主线阅读位置。

沿用 Pi 单 Agent 方向：业务程序明确切换 reading / reinforcement 模式并加载对应规则。同一个主 Agent 即可承担两类任务；模型生成内容与判定建议，程序校验、落库和显示状态。独立 Pi 最小验证不等于这两类正式业务已接入，仍需实施和验收。

## 二、下一步：卡片生成规则草案

### 1. 输入

当前学习约定及版本、节点及目标、必要前置内容、可用资料及来源状态、相关用户反馈、已有卡片。个人资料按相关性读取，不全量塞入。

### 2. 编排原则

- 一个节点可以有多张卡片，每张卡完成一个清楚的小目标；不固定为概念、案例、思考题三张。
- 当前讲解偏好：先说明是什么、再说明用途，以简单数字或具体情境举例，必要时说明条件与局限。
- 根据内容合并或拆分步骤，不要求每张卡重复“是什么、用途、例子”全部结构。
- 示例展示完整解释，不以留题结尾；主线不插入强制作答、掌握确认或自评。
- 短内容优先，但不为字数截断必要定义、例子的条件或计算过程。保持原项目少量内容、多页呈现的方向。
- 只准备近期需要的内容，后续结合反馈补充；已读正文不因偏好变化批量重写。

### 2.1 标题层级与节点教学结构

知识节点是一个完整的小主题。左上角固定显示节点主标题，例如“股票是什么”；翻阅该节点的不同卡片时主标题保持不变。卡片内部使用当前页副标题，例如“定义与含义”“用数字理解份额”“持股比例与市值”。阅读位置另以页码表达，不将卡片副标题当成新的知识节点。

先为节点规划卡片顺序，再生成各页正文。概念型节点采用以下默认顺序：

| 环节 | 规范 | 必要性 |
| --- | --- | --- |
| 定义与诠释 | 给出准确、适合目标程度的定义；用白话解释关键术语、所属类别和核心特征 | 新概念必须建立；已讲过的概念可简短回顾并关联原节点 |
| 典型例子 | 明确情境和条件，解释例子与定义怎样对应；数字计算展示完整 | 默认提供，特别简单的概念可与定义同页 |
| 区分与边界 | 对比最易混淆的概念，或展示反例、适用条件和常见误解 | 有影响理解的混淆风险时必须覆盖 |
| 用途与拓展 | 说明为什么学、在哪里用，再提供与目标有关的延伸 | 用途可前置；深入拓展按需，不无限增加主线 |
| 收束与衔接 | 简短回扣本节点核心关系，说明下一个节点承接什么 | 可并入末页，不必额外生成一张总结卡 |

环节不等于固定页数。定义较复杂时拆为定义和诠释两页；简单时合并。一个例子可以跨页，但拆页后要保留必要上下文。类比帮助理解，不替代正式含义；公式不替代变量和条件说明。

允许情境或例子作为短引入，但不能长期绕过定义。程序型、案例型、历史专题等节点按目标采用步骤、背景、证据、因果等结构，保留必要的概念说明，不机械套用所有概念型环节。

“股票是什么”节点的页序示例：定义与白话诠释 → 持股份额的数字例子 → 持股比例与市值的区分 → 股东权益的必要边界及与后续收益主题的衔接。正文须由资料支持，示例页序本身不代表相关内容已检索核验。

### 3. 输出

每张卡至少包含：卡片 ID（程序生成）、所属节点 ID、内容版本、小目标、标题、正文、资料引用和来源状态。例子中的数字、单位和结论应能相互核对。

另保存节点级卡片计划：主标题、目标、已有前置内容、各页顺序与职责、哪些必要内容已覆盖。正文输出中的标题是页内副标题；节点主标题由界面从节点读取。每次滚动生成都读取该计划，避免重复定义、例子提前使用未解释术语或漏掉边界。

模型结果由程序检查节点引用、字段和重复内容，再保存。程序校验能检查结构，不等于已经验证知识正确；来源核验与内容检查仍需落实。

内容检查至少回答：定义是否准确且得到解释；例子是否对应定义；有无遗漏必要条件；易混淆项是否澄清；拓展是否服务本次目标；页间是否连贯；是否无意插入要求作答的题目。不能以“每张足够短”替代节点教学完整性。

### 4. 反馈触发范围

| 用户行为 | 处理 |
| --- | --- |
| 继续翻页 | 保存位置，按路线自然推进 |
| 主动提问 | 针对发问时的卡片回答，保存关联 |
| 要求换例子或说太难 | 先调整当前解释，再影响尚未生成的相关内容 |
| 改变学习目标 | 返回约定与框架修订，保留既有记录 |
| 主动进入加强学习 | 保存当前阅读位置，切换独立模式 |

不因没有提问就判断已掌握，不因没有做加强学习就判断不积极。

## 三、接下来如何模拟

先展示一个节点的完整页序计划，再生成少量连续样例，观察定义、诠释、例子、区分和衔接；不为凑三张而删掉必要环节，不附测验。再单独模拟从知识树进入加强学习、通过/退出与恢复阅读，以验证两条流程互不打断。

首轮验收重点：能自然连续阅读；主动提问对应正确卡片；首次浏览点亮；加强入口不弹出；检查结果不改变阅读进度；中途退出回到原位置。以上均为待执行的产品案例，本轮文档写入不代表功能已实现。
